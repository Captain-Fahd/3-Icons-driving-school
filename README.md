# 3 Icons Driving School
This is a NextJS React app, w/ ChakraUI for styling, made for the driving school "3Icons Driving School". This is a new website for them to handle the following:
 - Display pricing for their packages
 - Send booking requests to the designated email via EmailJS API
 - Provide a good first impression to any upcoming students
